# ButtonGroup 按钮组

ButtonGroup 用于将多个 Button 组合为一组相近操作。

## API

### 属性

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| type | 统一设置子按钮类型 | string | — |
| size | 统一设置子按钮尺寸 | string | — |
| direction | 排列方向：horizontal / vertical | string | horizontal |

### 插槽

| 名称 | 说明 |
| --- | --- |
| default | Button 子组件 |

## 使用说明

从 `cool-design` 导入 `ButtonGroup`，并在默认插槽中放置 `Button`。
