# CheckboxGroup 复选框组

CheckboxGroup 管理一组 Checkbox 的数组值，并支持 `min`、`max` 和整体禁用。

## API

| 参数       | 说明            | 类型     | 默认值 |
| ---------- | --------------- | -------- | ------ | ----------- | --- |
| modelValue | 选中值数组      | `(string | number | boolean)[]` | []  |
| min / max  | 最少/最多选项数 | number   | —      |
| disabled   | 禁用整个组      | boolean  | false  |
