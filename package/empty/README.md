# Empty 空状态

### 介绍

在暂无数据时提供说明、插画和后续操作入口。

## API

### 属性

| 参数        | 说明                             | 类型   | 默认值   |
| ----------- | -------------------------------- | ------ | -------- |
| description | 空态描述                         | string | 暂无数据 |
| image       | 自定义图片地址，默认使用内置 SVG | string | —        |
| imageSize   | 图片宽高，支持数字或 CSS 尺寸 | number / string | 64 |

### 插槽

| 名称        | 说明             |
| ----------- | ---------------- |
| image       | 替换插画         |
| description | 替换描述         |
| default     | 重试、重置等操作 |

## 使用说明

-   `description`: 默认“暂无数据”。
-   `image`: 可选图片地址；默认使用内置 SVG，不请求外部图片。
-   `image` 插槽：替换插画。
-   `description` 插槽：替换描述。
-   默认插槽：重置、重试等操作。

Table 默认空态复用 Empty；自定义 Table empty 插槽仍然优先。
