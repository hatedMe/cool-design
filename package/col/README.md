# Col 列布局

### 介绍

通过列宽和偏移划分桌面内容区域，与 Row 配合使用。

## API

### 属性

| 参数   | 说明                    | 类型   | 默认值 |
| ------ | ----------------------- | ------ | ------ |
| tag    | 根节点标签              | string | div    |
| span   | 占据的栅格数（24 栅格） | number | 24     |
| offset | 左侧偏移栅格数          | number | 0      |

### 插槽

| 名称    | 说明     |
| ------- | -------- |
| default | 列内内容 |

## 使用说明

在 Row 内使用，默认插槽放内容。首版支持 tag（默认 div）、span（默认 24）、offset（默认 0），以 24 栅格为单位；继承 Row gutter，左右各一半。

历史 pull/push/xs/sm/md/lg/xl 暂保留声明，首版未实现其布局行为，不属于稳定能力。
