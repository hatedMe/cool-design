# Affix 固钉

### 介绍

将元素固定在页面（或指定滚动容器）的顶部或底部，常用于操作栏、返回顶部入口等场景。

## 基础用法

滚动页面时，距离顶部不足 `offset-top` 的元素会被固定在视口顶部。

```vue
<Affix :offset-top="20">
  <Button type="primary">固定在顶部</Button>
</Affix>
```

设置 `position="bottom"` 与 `offset-bottom` 可固定在视口底部；`target` 传 CSS 选择器可将元素固定在指定滚动容器内。

## API

### 属性

| 参数          | 说明                                       | 类型               | 默认值 |
| ------------- | ------------------------------------------ | ------------------ | ------ |
| `offsetTop`   | 固定位置距顶部的偏移                       | `number`           | `0`    |
| `offsetBottom` | 固定位置距底部的偏移，`position` 为 `bottom` 时生效 | `number`    | —      |
| `position`    | 固定方向：`top` / `bottom`                 | `string`           | `top`  |
| `target`      | 滚动容器的 CSS 选择器，默认为窗口          | `string`           | —      |
| `zIndex`      | 固定时的层级                               | `number`           | `100`  |

### 事件

| 事件名   | 说明                     | 回调参数          |
| -------- | ------------------------ | ----------------- |
| `change` | 固定状态变化时触发       | `fixed: boolean`  |

### 插槽

| 名称      | 说明         |
| --------- | ------------ |
| `default` | 被固定的内容 |

### 实例方法

| 方法       | 说明                         |
| ---------- | ---------------------------- |
| `update()` | 手动重新计算固定状态与位置   |
