# Autocomplete 自动补全

### 介绍

根据输入内容展示建议项，支持静态 `suggestions` 和 `fetch-suggestions`。

## 用法

`<Autocomplete v-model="value" :suggestions="items" clearable />`。

## API

属性：`modelValue`、`suggestions`、`fetch-suggestions`、`placeholder`、`trigger-on-focus`、`disabled`、`clearable`。

事件：`update:modelValue`、`input`、`change`、`select`、`focus`、`blur`、`clear`。
